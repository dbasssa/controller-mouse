# Controller-mouse
---
so simple you could literally make it yourself. I legit made this cuz i couldnt find an easy-to-use input wrapper. This one just requires `git clone` and `cd controller-mouse && cargo run`

The app basically just allows you to connect a controller and use it as a mouse. no GUI so you have to quit using the System Tray or Ctrl+C in the terminal. 


## Controls:
XB/PS
A/X: Left Click

## Movement: 
Left Stick: Move Cursor Position
Right Stick: Scroll Up/Down

--- 
Note: I have no idea if this works with bluetooth connections, but nothing says it shouldnt. Have fun.
